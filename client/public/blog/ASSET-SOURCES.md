# Blog visual assets

- `blog-hero.mp4` is a locally stored copy of Pexels video file `27980029`, selected from the technology-video search collection. It is used as a muted, decorative background only.
- Source search: https://www.pexels.com/search/videos/technology%20abstract/
- Pexels license reference: https://www.pexels.com/license/
- The eight files in `photos/` are locally stored, compressed Pexels photographs selected for the article topics. They are used as editorial thumbnails and are not embedded as remote URLs.
- `photos/photo-analytics.jpg` is also used as the video poster and social-sharing fallback image.
- Photo source search: https://www.pexels.com/search/digital%20marketing/
